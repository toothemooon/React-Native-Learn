## 2024-03-20 - Adding Tactile Feedback & Semantics to React Native Custom Cards
**Learning:** `Pressable` in React Native provides a robust primitive for interaction, but out-of-the-box it lacks native visual feedback and implicit accessibility semantics for complex nested children like hero cards. A common pattern is applying style functions `({ pressed }) => [...]` to simulate visual tactile responses (e.g., modifying `transform` scales and `opacity`), but omitting accessibility roles limits screen reader usability. Complex nested views in a `Pressable` often benefit from an explicit `accessibilityRole="button"`, and combining children's text context into an explicit `accessibilityLabel` alongside a contextual `accessibilityHint` provides a vastly superior experience.
**Action:** When implementing custom cards or complex buttons using `Pressable`, systematically provide a visual tactile response with the `pressed` state style pattern and *always* enforce explicit `accessibilityRole`, `accessibilityLabel`, and `accessibilityHint` properties.
