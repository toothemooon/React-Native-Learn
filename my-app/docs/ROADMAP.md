# 电子木鱼 (WoodenFish) - 演进路线图 (ROADMAP)

**产品愿景**：从单一的“解压小玩具”升维为“高留存的正念冥想平台”。通过“内容货架（Library）”与“全局沉浸播放器（Player）”的分离，打造类似 Calm/Spotify 的平台级生态体验。

---

## 阶段一：打磨极简核心引擎 (Phase 1: The Engine) - 🟡 进行中
**目标**：完成核心敲击模块的视觉与物理反馈打磨，使其具备成为“全局沉浸播放器”底层引擎的资格。
- [x] **视觉定调**：实现 3D 质感 SVG 木鱼与径向光影效果。
- [x] **交互闭环**：添加 Animated 点击水波纹涟漪。
- [x] **控制台重构**：剥离系统设置，实现 Bento Box 样式的半沉浸“法器配置（调音台）”，并实装 Cover Flow 音色画廊纯 UI。
- [x] **系统解耦**：将 App 基础设置放入右上角独立全屏 Modal（解决 4.3 审核风险）。
- [ ] **状态管理 (Zustand)**：引入全局状态，持久化存储配置（AsyncStorage）。
- [ ] **听觉与触觉 (Audio & Haptics)**：打通真实的 `expo-av` 极低延迟音频和 `expo-haptics` 物理震动反馈。

---

## 阶段二：平台化架构重构 (Phase 2: Platform Shift) - ⏳ 待启动
**目标**：引入全局路由，将 App 从“单页面”重构为“底层生态 Tab + 顶层沉浸 Player”的现代化 App 架构。
- [ ] **引入 React Navigation**：搭建路由骨架。
- [ ] **四向 Bottom Tabs 建设**：
  - **禅境 (Home)**：大画幅动态背景，每日推荐 Hero 卡片（Daily Zen）。
  - **法器 (Discover)**：横向扩展的内容货架（白噪音、法器音色馆）。
  - **功德 (Journey)**：用户历程统计展示。
  - **我的 (Profile)**：账户与系统级设置下放。
- [ ] **全局沉浸播放器 (Global Modal Player)**：
  - 将阶段一开发的木鱼主界面封装为全局 `presentation: 'modal'` 覆盖页。
  - 实现 Tab 栏上方的悬浮 Mini-Player（迷你控制条），支持在后台自动敲击/播放白噪音的同时浏览 App。

---

## 阶段三：Dark Zen 生态与成长系统 (Phase 3: Ecosystem & Growth)
**目标**：丰满各个 Tab 的内容，引入动态视觉环境，并用成长系统建立长期留存。
- [ ] **Dark Zen 环境视觉**：在 Home 和 Discover 引入深色调流体、流云等动态背景（考虑 Lottie 或基础 Skia）。
- [ ] **多轨混音引擎**：允许用户同时播放“木鱼敲击音”与“环境白噪音（雨声、篝火等）”。
- [ ] **包浆成长系统**：根据用户的累计敲击次数和冥想时长，木鱼模型视觉发生从“新木”到“包浆（高光柔和）”的物理级变化。
- [ ] **健康数据联动**：深度对接 Apple Health / Google Fit，将自动敲击/停留时间写入“正念分钟数”。

---

## 阶段四：商业化与云端延展 (Phase 4: Monetization & Cloud)
**目标**：平滑地进行商业化变现与轻社交探索，绝不破坏核心禅意。
- [ ] **IAP 商业化体系**：将特殊材质法器（如赛博风、玉石）、高级环境音（特定白噪音）锁入订阅或一次性内购。
- [ ] **云禅房 (WebSockets)**：支持轻社交，同房间内的用户产生的水波纹可互相可见（极简无文字社交）。
- [ ] **多端账户同步**：云端备份用户配置、包浆进度与总功德量。

---

## ⚠️ 开发原则与防翻车指南
1. **Z 轴空间隔离**：所有的“挑选/浏览”动作发生在 Tab 栈内（淡入淡出）；所有的“执行/沉浸”动作发生在上推的全屏 Modal 内（Slide Up）。
2. **警惕过度渲染**：多轨音频引擎和全局动态背景可能会严重吃内存，必须在 Phase 3 开始前建立严格的 60FPS 性能基线。
