# 演进路线图：WoodenFish (木鱼)

从单一解压工具升维至高留存正念冥想生态平台的四阶段路线图。根据 **“UI 铺设 ➔ 逻辑与引擎接入”** 的渐进演进顺序以及当前项目的最新进展进行规划。

---

## 阶段一：视觉骨架与静态 UI 铺设 —— ✅ 已完成
打破单页工具的局限，解耦核心模块，完成各核心页面首屏的高保真静态视觉落地。
*   **平台化路由架设**: 引入 `@react-navigation`，搭建“禅修”、“木鱼”（中间页，保持原样）、“禅师”三向底部悬浮标签导航以及全屏沉浸播放器 Modal 栈。
*   **“禅修”页静态 UI (左页)**: 成功落地 2x3 环境音选择网格、1x3 核心法器卡片静态 UI 布局，霓虹薄荷绿选中态极细边框，底置“开始禅修”幽灵发光态按钮。
*   **“禅师”页静态 UI (右页)**: 成功落地智能聊天室首屏，包括 🧘 头像、消息气泡流（禅师气泡左侧带有极细绿色立条装饰）、智能发送输入框底座，并支持 1000ms 智能禅修智慧答复的交互模拟。
*   **安全适配与工程底座**: 项目全量启用 TypeScript 类型定义，全局 Modal 引入 `<SafeAreaProvider>` 避让刘海区，奠定规范的“Dark Zen”色彩体系。

---

## 阶段二：极致感官 UI 与动效精雕 (当前阶段) —— 🟡 进行中
在此阶段，我们继续精雕细琢所有的前台视觉元素、极致微动效与拟物化 UI 资产，在不接入复杂底层逻辑前，确保静态/拟态体验达到极高水准。
*   **付费墙玻璃遮罩与解锁 UI**: 
    *   在“禅师”聊天室中引入 `expo-blur`，实现非 Pro 用户历史气泡/输入框的玻璃拟态遮罩。
    *   设计极富禅意的“金边锁扣”与“解锁/订阅 VIP”提示卡片 UI，形成视觉闭环。
*   **环境音与法器配置面板 UI 细化**: 
    *   细化“禅修”页各环境音卡片的交互反馈（微缩放与发光过渡动效）。
    *   设计并铺设独立的环境音量微调滑杆（Slider）视觉样式。
*   **高性能动态粒子背景 (Skia UI)**: 
    *   引入 `@shopify/react-native-skia`，在背景层铺设超低延迟的动态“禅意流云”或“雾气弥漫”微粒动效，提升视觉的呼吸感与禅意。
*   **木鱼受击光影变化与特效 UI (Skia UI)**: 
    *   利用 Skia 编写木鱼敲击时的 3D 材质光影变化（微压塌、高光瞬间收缩与水波纹发光波纹扩散的视觉，仅作静态和本地计时模拟，**保持中间页原有代码结构和功能不受影响**）。
*   **订阅与商业化购买落地页 UI**: 
    *   设计极简美学的 VIP 购买弹窗 UI，包含多档订阅对比卡片与优雅的卡片切换动效。

---

## 阶段三：核心交互逻辑与底层引擎实现 —— ⏳ 待规划
在视觉与动效完全确立后，接入底层音频、震动引擎与状态持久化方案，将静态页面与交互动作真正激活。
*   **零延迟听觉引擎 (expo-av)**: 
    *   正式接入 `expo-av` 引擎，实现 Tab 1（“禅修”页）选中的法器在被敲击时的 0ms 低延迟清脆发声。
*   **多通道白噪音混音系统**: 
    *   实现环境音卡片多通道叠加混播逻辑，并根据 Slider 的值实时控制音量比例。
*   **细腻物理触觉反馈 (expo-haptics)**: 
    *   全面接入触觉引擎，在敲击瞬间、网格点击、刻度滑动时触发不同物理级别的微震动。
*   **全局数据持久化与缓存 (Zustand + AsyncStorage)**: 
    *   搭建全局状态管理，保存用户的 strikes 计数、累计修持天数、当前选择的法器与环境音，实现多页无缝同步。
*   **智能 AI 禅师真实对接**: 
    *   将“禅师”右页的模拟对话流，对接真实的后端 AI 接口或大模型 API，实现真正具备心理疏导与禅意智慧的问答逻辑。

---

## 阶段四：高阶生态功能与商业化系统接入 —— ⏳ 待规划
打通系统级生态，引入包浆养成、弱联机及商业变现，完成整个生态闭环。
*   **健康生态同步 (HealthKit)**: 
    *   接入 Apple Health 或 Android 运动健康，将每日正念冥想分钟数无缝同步至系统健康中心。
*   **木鱼盘玩包浆演算**: 
    *   根据全局 strikes 累计计数，动态改变木鱼的材质纹理与光泽度（通过算法渲染实现渐进式“盘玩包浆”），为用户提供长线目标。
*   **在线禅房共振 (WebSocket)**: 
    *   构建弱社交禅房，当同频修行者敲击时，通过 WebSocket 将数据广播至同房间用户，并在屏幕边缘产生波纹共振。
*   **支付与内购系统对接 (StoreKit/Google Play Billing)**: 
    *   正式打通应用商店支付，校验 VIP 状态，控制非 Pro 用户的玻璃遮罩是否解锁。
