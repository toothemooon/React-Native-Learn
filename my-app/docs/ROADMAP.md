# 开发路线图 (Roadmap)

> 最后更新：2026-04-28

---

## Phase 1 — UI 复刻（进行中）

目标：静态界面与原版视觉 1:1 对齐。

### 已完成
- [x] **TypeScript 全面迁移**：启用 TS 强化类型安全
- [x] 主界面布局（纯黑背景 + 顶栏）
- [x] 木鱼矢量图 + 按压动画
- [x] 设置面板（Modal）
  - [x] 悬浮文字输入框
  - [x] 播放模式 (自动/手敲) 切换 UI
  - [x] 停止模式 (永不/计数/倒计时) 配置 UI
  - [x] 音色网格（00–12 + BUY 角标）
  - [x] 操作列表

### 待完成
- [ ] **粒子飘字动画**：点击后在木鱼上方生成上浮淡出的文字粒子
- [ ] **滑块组件**：将静态间隔/偏差滑块替换为真实可拖动的 `@react-native-community/slider`

---

## Phase 2 — 逻辑打通

目标：完成"视·听·触"完整反馈闭环。

- [ ] **触觉震动**：接入 `expo-haptics`，每次敲击触发 `ImpactFeedbackStyle.Light`
- [ ] **音频播放**：接入 `expo-av`，实现音色缓存池与打断式重播
- [ ] **自动敲击引擎**：基于 `setInterval` + 偏差算法的自动化敲击模式
- [ ] **Zustand Store**：全局状态管理，替换所有本地 state
- [ ] **数据持久化**：使用 `AsyncStorage` 保存用户偏好

---

## Phase 3 — 差异化演进

目标：在复刻基础上建立独特产品价值。

- [ ] 替换视觉主体（如磬、铃铛等其他法器）
- [ ] 主题皮肤系统（自定义颜色）
- [ ] 成就/打卡系统
- [ ] IAP 解锁更多音色与皮肤
