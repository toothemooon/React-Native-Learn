# 开发路线图 (Roadmap)

> 最后更新：2026-04-30

---

## Phase 1 — 核心 UI 与状态层（进行中）

目标：完成静态界面与原版视觉 1:1 对齐，随后进行 UI 质感的极致精雕，最后搭建坚实的状态管理与持久化基础。
**🏆 阶段成功指标 (Success Metrics)**：
- 核心敲击路径与配置面板无缝运行，不出现 UI 卡顿。
- 在低端测试机上保持 60 FPS 稳定帧率基线。
- **⚠️ 截止标准**：UI 精雕达到“顺滑、无明显视觉廉价感”即可，能跑通核心用户路径即进入 Phase 2，防止在过度打磨中失速。

### 已完成
- [x] **TypeScript 全面迁移**：启用 TS 强化类型安全
- [x] 主界面布局（纯黑背景 + 顶栏）
- [x] 木鱼矢量图 + 按压动画
- [x] 设置面板（Modal）
  - [x] 悬浮文字输入框
  - [x] 播放模式 (自动/手敲) 切换 UI
  - [x] 停止模式 (永不/计数/倒计时) 配置 UI
  - [x] 音色网格（00–12 + BUY 角标）
  - [x] 操作列表

### 待完成（专注 UI 精雕）
- [ ] **高级面板重塑**：引入 `expo-blur` 毛玻璃遮罩，优化字体排版、呼吸感字间距，以及组件切换的淡入淡出动画。
- [ ] **木鱼图形质感升级**：引入 SVG 渐变 (`RadialGradient`) 与物理光影反馈。
- [ ] **微交互反馈**：点击木鱼时增加局部水波纹 (Ripple) 扩散涟漪效果。
- [ ] **定制滑块 UI**：真实可拖动 `@react-native-community/slider` 极简样式。

### 待完成（状态层搭建）
- [ ] **状态抽离 (Zustand)**：引入 Zustand，将 SettingsPanel 中的本地状态抽离为全局 Store。
- [ ] **数据持久化**：结合 AsyncStorage，实现本地存储。

---

## Phase 2 — 核心视·听·触反馈与商业化基础

目标：建立基础但极具沉浸感的物理敲击反馈闭环，并跑通商业化基础逻辑。
**🏆 阶段成功指标 (Success Metrics)**：
- 触觉与听觉触发延迟 < 50ms，做到“指引声至”。
- 次日留存率基线确立。
- 走通 App Store / Google Play 支付沙盒。

- [ ] **粒子飘字动画**：每次敲击生成上浮淡出的文字粒子。
- [ ] **基础触觉与音频**：接入 `expo-haptics` 与 `expo-av`，验证最核心的沉浸反馈。
- [ ] **白噪音混音**：支持在敲击的同时，开启背景白噪音（流水、篝火等环境音）。
- [ ] **基础商业化链路 (IAP)**：跑通内购流程，实现基础音色与“高级白噪音”包的购买解锁体验。

---

## Phase 3 — 意境生态、收集与高级交互

目标：通过差异化叙事和收集系统建立长期留存动机，并探索高级物理交互收益。
**🏆 阶段成功指标 (Success Metrics)**：
- 用户平均单次停留时长（正念时长）显著增加。
- App Store 审核通过率提升（得益于健康数据联动带来的功能性评价）。

- [ ] **包浆与视觉成长系统**：基于累计敲击次数渐进改变木鱼光泽。
- [ ] **音色收集系统**：通过特定节日、特定敲击次数解锁隐藏音效。
- [ ] **材质与动态环境皮肤**：金属钵/玉石等材质切换。
- [ ] **健康数据联动**：将敲击与冥想时长写入 Apple Health/Google Fit。
- [ ] **桌面/锁屏 Widget**：支持灵动岛、锁屏实时活动或桌面小组件展示进度。
- [ ] **复杂物理交互 (探索)**：在核心体验达标后，验证“长按连击”、“滑动摩擦颂钵”以及“重力感应摇晃”的用户价值与实现成本。

---

## Phase 4 (独立项目) — 云禅房 (全球共振)

目标：引入弱社交属性，建立宏大的共鸣意境。
**⚠️ 复杂度预警**：属于重量级功能，强依赖后端基础设施开发与运维部署。

- [ ] **WebSocket 基础设施搭建**：服务端高并发短连接支持。
- [ ] **全球波纹同步**：在背景展示同频在线用户的敲击波纹反馈。
- [ ] **在线人数面板**：极简的当前宇宙共修人数统计。
