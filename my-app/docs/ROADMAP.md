# 开发路线图 (Roadmap)

> 最后更新：2026-04-30

---

## Phase 1 — 核心 UI 与状态层（进行中）

目标：完成静态界面与原版视觉 1:1 对齐，随后进行 UI 质感的极致精雕，最后搭建坚实的状态管理与持久化基础。

### 已完成
- [x] **TypeScript 全面迁移**：启用 TS 强化类型安全
- [x] 主界面布局（纯黑背景 + 顶栏）
- [x] 木鱼矢量图 + 按压动画
- [x] 设置面板（Modal）
  - [x] 悬浮文字输入框
  - [x] 播放模式 (自动/手敲) 切换 UI
  - [x] 停止模式 (永不/计数/倒计时) 配置 UI
  - [x] 音色网格（00–12 + BUY 角标）
  - [x] 操作列表

### 待完成（专注 UI 精雕）
- [ ] **高级面板重塑**：引入 `expo-blur` 毛玻璃遮罩，优化字体排版、呼吸感字间距，以及组件切换的淡入淡出动画。
- [ ] **木鱼图形质感升级**：引入 SVG 渐变 (`RadialGradient`) 与阴影，实现 3D 物理下压光影反馈，并为多材质做资产预研。
- [ ] **微交互反馈**：点击木鱼时增加局部水波纹 (Ripple) 扩散涟漪效果。
- [ ] **定制滑块 UI**：引入真实可拖动的 `@react-native-community/slider`，并将轨道与拖动把手深度定制为极简高级风格。

### 待完成（状态层搭建）
- [ ] **状态抽离 (Zustand)**：引入 Zustand，将 SettingsPanel 中的本地状态抽离为全局 Store。
- [ ] **数据持久化**：结合 AsyncStorage，实现用户偏好设置的本地存储。

---

## Phase 2 — 视·听·触反馈闭环 & 深度交互

目标：在基础敲击反馈之上，打破单一交互，引入更具“物理真实感”的体验。

- [ ] **粒子飘字动画**：每次敲击生成上浮淡出的文字粒子。
- [ ] **基础触觉与音频**：接入 `expo-haptics` 与 `expo-av`。
- [ ] **复杂手势引擎 (New)**：支持“长按”由慢到快连击，以及“绕圈滑动”触发摩擦低鸣声（颂钵体验）。
- [ ] **重力感应联动 (New)**：接入 `expo-sensors`，摇晃手机触发物理碰撞零碎声。
- [ ] **白噪音混音 (New)**：支持在敲击的同时，开启背景白噪音（流水、篝火等环境音）。

---

## Phase 3 — 意境化与生态打通 (差异化演进)

目标：从“工具”转变为“意境”，建立独特的收集与成长生态，并优化应用商店过审策略。

- [ ] **材质与动态环境皮肤**：金属钵/玉石/赛博等材质，配合极简动态环境背景（雨夜/雪山/流体烟雾）。
- [ ] **包浆与视觉成长系统**：基于累计敲击次数，渐进改变木鱼的光泽与背景亮度，带来长期成长感。
- [ ] **音色收集系统 (New)**：通过特定节日、特定敲击次数解锁隐藏音效（猫咪叫声、水滴声、8-bit 声等），将音色变为收集品。
- [ ] **健康数据联动**：将敲击与冥想时长写入 Apple Health/Google Fit（提升应用商店功能性评价）。
- [ ] **桌面/锁屏 Widget**：支持灵动岛、锁屏实时活动或桌面小组件展示进度。
- [ ] **云禅房（全球共振）**：WebSocket 实时交互，展示全球在线敲击波纹，建立弱社交共鸣。
