# 视觉与设计规范手册：WoodenFish

本文档规定了应用在视觉美学、色彩设计、转场反馈及商业化 UI 呈现上的技术规范。

---

## 1. 视觉定调：Dark Zen (暗黑禅意)
打造有温度、有呼吸感且防眼部疲劳的静谧空间。
*   **全局底色**: `#0B0D11`（深空暗夜蓝）— 用于普通页面，呈现深邃的空间层次感。
*   **沉浸播放器底色**: `#000000`（纯黑）— 用于 `PlayerScreen`，实现视线极致收敛。
*   **卡片与弹窗底色**: `#15171A` — 略亮于背景，拉开视觉纵深。

---

## 2. 色彩体系与设计 Token

### 核心调色板
| Token | HEX / 颜色值 | 角色说明 | 具体用途 |
| :--- | :--- | :--- | :--- |
| **全局背景底色** | `#0B0D11` | 基础空间色 | 禅修、木鱼、禅师三页根容器背景 |
| **卡片底色** | `#15171A` | 容器材质色 | 调试网格卡片、气泡消息卡片、设置选项面板 |
| **极细边框** | `rgba(255,255,255,0.05)` | Hairline 分割 | 卡片边框线、横向分隔线 |
| **主文字色** | `#E0E0E0` | 高亮标题与正文 | 问候语、会话文字、设置标题 |
| **次级文字色** | `#888888` | 低对比度文本说明 | 分类标题、次级信息说明、身份与时间时间标签 |
| **强调突出色** | `#FFFFFF` | 核心数字与指标 | 敲击计数、发送文本内容 |

### 战略强调色：霓虹薄荷绿
| Token | HEX / 颜色值 | 应用目的 |
| :--- | :--- | :--- |
| **高亮激活态** | `#D4FF59` | Active Tab 状态指示、选中卡片高亮边框/文字 |
| **幽灵发光态 CTA** | 背景 `rgba(212,255,89,0.1)` + 边框 `rgba(212,255,89,0.3)` | 核心按钮设计（如首屏的“开始禅修”按钮） |

> [!IMPORTANT]
> **幽灵发光态原则**：严禁大面积使用纯实色 `#D4FF59` 进行背景填充，这会导致严重的刺眼感与视觉疲劳。必须使用极低透明度填充底色配合轻度半透明描边，以达到呼吸态发光感。

## 3. 屏幕角色与信息架构

功能严格遵循三向分离，形成性感体验闭环：

| 页面 | 职责角色 | 组件路径 | 核心 UI 表现 |
| :--- | :--- | :--- | :--- |
| **禅修 (Home)** | 身体层 / 参数调试 | `HomeScreen` | 问候语，2x3 环境音选择网格，1x3 核心法器选择，底置“开始禅修”按钮。 |
| **木鱼 (Journey)** | 精神层 / 我的心境 | `JourneyScreen` | 60fps 呼吸矢量人像，连续禅修天数/累计统计大字（中间页，保持原样）。 |
| **禅师 (Profile)** | 悟道层 / 解忧会话 | `ProfileScreen` | AI 禅师对话流界面。包含禅师修行头像、气泡对话列表、自动滚动，以及底部带薄荷绿描边的发送输入框。 |
| **沉浸播放器** | 专注层 / 敲击法器 | `PlayerScreen` (Modal) | Strikes 计数大字，同心圆声波纹，核心木鱼交互，调音台入口。 |

## 4. AI 禅师对话与气泡视觉规范

重构后的聊天室具备严格的视觉标准，在突出禅意的同时保障可读性：

### 禅师消息气泡 (左对齐)
*   **气泡底色**: 标准卡片暗底 `#15171A`，辅以 `rgba(255,255,255,0.03)` 极淡微发光边缘。
*   **左侧装饰条**: **气泡最左侧应用极细的薄荷绿装饰条 (`borderLeftColor: '#D4FF59'`, borderLeftWidth: 3)**，这是禅师高档视觉的绝对锚点。
*   **身份小标**: 气泡左下方显示 `#555555` 颜色的“禅师”或“禅师 · 会话结束后”时间标签，距离气泡 `6px`，保持呼吸感。

### 用户消息气泡 (右对齐)
*   **气泡底色**: 略带蓝调的微亮卡片色 `#1A1C1E`。
*   **身份小标**: 气泡右下方显示“你”，字色为 `#555555`。

## 5. 安全区域 (Safe Area) 与布局规范

*   **普通页面**: 使用 `<SafeAreaView edges={['top']}>`，底部安全边距由 Bottom Tabs 自动控制。
*   **全屏 Modal 浮层**: 必须在根部声明新的 `SafeAreaProvider`，并用 `<SafeAreaView edges={['top', 'bottom']}>` 包裹内容，确保刘海屏适配。

## 6. 动效与交互反馈机制

### 空间与转场
*   **播放器唤起**: 自下而上模态滑入 (`presentation: 'modal'`)。播放器关闭后，HomeScreen 执行 800ms 柔和淡入，引导用户视觉焦点的复原。

### 交互触觉反馈
*   **按压态**: 所有 `Pressable` 交互组件（包括环境音卡片、法器卡片、发送按钮）统一配置按压态。主要确认按钮触发 `ImpactFeedbackStyle.Medium` 物理震动反馈。
*   **滑块操作**: 调音台 (`SettingsPanel`) 刻度滑动时，每拨动一格触发细微的轻触震动反馈 (`ImpactFeedbackStyle.Light`)。
