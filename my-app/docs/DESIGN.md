# 电子木鱼 (WoodenFish) - 视觉与架构设计规范

## 1. 核心架构哲学 (Architecture Philosophy)
本产品采用**“内容货架（Library）”与“沉浸式播放器（Player）”分离**的现代平台架构（参考 Calm / Spotify）：
- **底层（生态层）**：由 Bottom Tabs 构成，承担“发现、挑选、统计、管理”的逻辑任务。
- **顶层（沉浸层）**：一个可全局唤起、滑出覆盖全屏的 Player Modal。在这里，一切与当前体验无关的元素（包括 Tab 栏）都会被隐藏，让用户 100% 专注。

## 2. 视觉定调：Dark Zen (暗黑禅意)
抛弃传统的“绝对死黑 + 亮白”的冷硬工具风，转向有温度、有呼吸感的空间设计。

### 色彩体系 (Color Palette)
- **底层空间色 (Background)**：深空灰 (`#121214`)、暗夜绿 (`#0E1412`)、午夜蓝 (`#0D1117`) 的极暗冷色调，配合缓慢流动的光影。
- **沉浸层底色 (Player Base)**：使用最纯净的纯黑 (`#000000`) 配合微弱的同心圆，以达到极致的视线收敛。
- **卡片材质 (Material)**：使用带有非常微弱的透明度（如 `rgba(255,255,255, 0.03)`）配合极细边框（Hairline Border: `#2A2A2C`），使底层环境光能隐约透出。
- **品牌高光 (Accent)**：柔和的暖光（如暗金 `#A09050` 或檀木色），避免刺眼的纯白色。

### 排版与字体 (Typography)
- **非沉浸区（Home / 每日一禅）**：在感性文案（如“早安”、“夜深了”）中使用**衬线体 (Serif)**，增加人文温度。
- **沉浸操作区（播放器/控制台）**：使用极简的**无衬线体 (Sans-Serif)**，并在英文/数字（如 S E T T I N G S、0.5s）中加大字间距（Letter Spacing），传递空灵感。

## 3. 布局与组件规范 (Layout & Components)
### Home (禅境) Tab
- **全屏动态背景**：整个 Tab 无明显边界。
- **Hero 卡片 (Daily Zen)**：占据上半屏，推荐当天的“音景组合”。
- **横向画廊**：保留最近使用的法器快捷入口。

### Player (沉浸播放器) 
- 这是一个 Z-Index 最高的 Modal 弹窗。
- **向下收起**：顶部需保留极其克制的下拉指示器 (`∨` 或短横线)，告知用户可将其收缩为全局悬浮的 Mini-Player。
- **无感交互**：所有的调整动作通过底部的“调整法器”呼出 Bento Box 半屏抽屉，绝不跳页。

### Settings (控制台) - Bento Box
- 打破线性表单布局，将高频功能封装为 2x2 或更具参差感的卡片矩阵。
- 引入**渐进式展示 (Progressive Disclosure)**，例如关闭自动模式时，频率刻度尺自动降维暗化。

## 4. 动效语言 (Motion Language)
1. **空间转换**：
   - 唤起沉浸播放器：自下而上覆盖 (Slide Up)。
   - 收起沉浸播放器：向下滑动，变身悬浮 Mini-Player。
2. **手势与物理**：
   - 滑块与刻度尺：必须具有物理阻尼感，且每拨动一格产生细微的 Haptics 震动。
   - 木鱼点击：不仅要有 Animated 缩放回弹，还要辅以水波纹（Ripple）涟漪透明度消散。
