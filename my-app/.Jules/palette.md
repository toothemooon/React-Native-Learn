
## 2024-05-24 - React Native Pressable Tactile Feedback Pattern
**Learning:** The `Pressable` component in React Native natively supports visual feedback patterns via dynamic styling using the `({ pressed }) => [...]` syntax, avoiding the need for complex state management for simple button presses.
**Action:** Apply this pattern consistently across custom buttons and cards to improve tactile feedback, scaling down (`scale: 0.96`) and slightly reducing opacity (`opacity: 0.8`) on press to provide a more intuitive touch experience.
