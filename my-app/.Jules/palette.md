## 2025-02-27 - Enhance Accessibility for Locked Cover Flow Gallery Cards
**Learning:** In React Native, implementing custom UI toggleable/selectable cards via `Pressable` requires explicitly managing `accessibilityState={{ disabled: boolean }}` and `disabled={boolean}` for non-interactive states to let assistive technologies properly announce the status without manual condition checks in `onPress`. Tactile feedback on interactive components lacks native visual feedback and requires `style={({ pressed }) => [...]}` pattern to visually indicate it.
**Action:** Always add native tactile feedback scaling (`transform: [{ scale }]`) and explicitly map component logical state to semantic ARIA props (e.g., `accessibilityRole="button"`, `accessibilityLabel`, `accessibilityHint`, and `accessibilityState`) when implementing custom selectable lists/cards using `Pressable`.
