## 2024-05-10 - Missing Accessibility & Feedback on Custom Pressable Cards
**Learning:** I found a recurring pattern in this app's components: custom `Pressable` cards (like the "Daily Zen" Hero Card on the Home screen) lacked proper native tactile feedback (such as scaling or opacity changes) and crucial screen reader accessibility attributes (`accessibilityRole`, `accessibilityLabel`, and `accessibilityHint`). The `Pressable` component in React Native doesn't have default visual feedback unlike `TouchableOpacity` or `TouchableHighlight`, meaning users get no visual indication that their tap was registered unless we explicitly add it. Furthermore, without a role and label, screen readers will read all inner text elements separately, creating a confusing experience instead of announcing it as a single interactive element.
**Action:** Always use the `style={({ pressed }) => [...]}` pattern for `Pressable` to add tactile feedback (e.g., slight opacity drop or scaling down). Additionally, consistently apply `accessibilityRole="button"`, a descriptive `accessibilityLabel`, and an `accessibilityHint` to group the card's content for screen reader users so they know it's actionable and what action it performs.
